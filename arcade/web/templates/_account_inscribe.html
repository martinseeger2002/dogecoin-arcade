{# The two ways an account puts something on the chain, in one place, because there are two pages that offer them and an inscription cannot be taken back from a page that got the transaction wrong. `/me/nfts` has always had these. The public `/nfts` page needs them too, and not as a link: on a public instance the node has no key to inscribe with, so the controls that page carried -- the wizard link and the two forms that post to `/inscriptions/create` -- were buttons that answered "Not here" to the one person who could have made the thing. The operator met them on 2026-09-24. So the markup is included and the script below belongs to it. It talks to the page through three things only: the `#news` and `#trouble` rows the host page already carries, the `#file`/`#build`/`#run-*` ids below, and the chain this page is drawn for. Nothing here spends anything the tab has not been shown and agreed to: every transaction is offered unsigned by this node, read back by `wallet.checked` out of the transaction's own bytes, and signed here. #}

Inscribe one thing

A little under 7,500 bytes go on in one transaction; anything bigger goes on in several, one signature each, and both are paid for by this account and signed in this tab, so this node never sees the key that spent it. The first transaction splits this account's coins into one output per piece and each piece spends its own, so a file costs one block — the split's — and then every piece goes at once, rather than one piece per block. It cannot be taken back afterwards, and this node keeps no copy of the file: if this tab closes, choose the same file again and it carries on where it stopped.

Run a collection

A folder laid out the way the Art Engine leaves one — json/_metadata.json and the pictures. Each item goes up in its own transaction, signed here, one at a time: this tab stays open while the run is going, and if it closes the run is still there when you come back, at the piece it stopped on. Your node paces it by the inscriptions it will take in an hour, and it keeps the pictures you uploaded — nothing throws them away yet.

The run

Every run this account has written down — the pieces, which one stopped it, and what it cost.
