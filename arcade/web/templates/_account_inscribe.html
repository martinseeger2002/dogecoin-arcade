Inscribe one thing

A little under 7,500 bytes go on in one transaction; anything bigger goes on in several, one signature each, and both are paid for by this account and signed in this tab, so this node never sees the key that spent it. The first transaction splits this account's coins into one output per piece and each piece spends its own, so a file costs one block — the split's — and then every piece goes at once, rather than one piece per block. It cannot be taken back afterwards, and this node keeps no copy of the file: if this tab closes, choose the same file again and it carries on where it stopped.

JSON beside the file (optional)

Metadata that goes on the chain with it: a name, or the mintpad / tokenpad object that makes a page of your own design a mintpad (see the Mintpads guide).

Run a collection

Choose the folder your collection is in. A HashLips Art Engine build folder works as it is (its images and json, with json/_metadata.json), and so does any folder of your own pictures. Every picture goes up exactly as it is — never shrunk. Each piece is its own inscription, signed here, one after another: this tab stays open while the run is going, and if it closes the run is still there when you come back, at the piece it stopped on. Your node paces it by the inscriptions it will take in an hour, and it keeps the pictures you uploaded — nothing throws them away yet.

What the JSON is, and what traits are

Every piece of a collection carries a little JSON beside its picture, on the chain with it. It says which collection the piece belongs to and its number — "name": "Sad Pho #12" and "edition": 12 — and that is how every node files the pieces into one set. It can also carry traits ("attributes"): what this piece is made of, like {"trait_type": "Background", "value": "Blue"}. Traits are what collectors filter and compare by, and how rare a trait is comes from how many pieces share it.

The HashLips Art Engine writes all of this for you, one <number>.json per picture and all of them together in _metadata.json. A folder of your own pictures has none: choose it anyway, and the wizard below writes it, with your collection's name, a description, and traits — the same for every piece, or each piece's own from a spreadsheet.
