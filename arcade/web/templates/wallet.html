Fast sending test

A long message or a file is sent as several linked transactions, and each one waits for the previous to confirm — because there is a single output to spend and each transaction has to use the change from the last.

Splitting that output into many small ones removes the waiting entirely: each transaction funds itself. Measured on this chain, a 40 KB file went from about four minutes to two seconds.
