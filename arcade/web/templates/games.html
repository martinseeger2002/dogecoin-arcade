Any HTML page you inscribe can be a game here. Put a game object in the inscription's JSON and it appears on this tab on every arcade, ranked by what people say about it. Inscribe a new version with the same name to replace the card.

{
  "game": {
    "name": "My Game",
    "description": "One line about it.",
    "version": "1.0",
    "players": "1-8",
    "multiplayer": true,
    "family": "my-game",
    "cover": "<txid of a picture you inscribed>",
    "genre": "puzzle"
  }
}

Only name is required. A multiplayer game uses arcade.realtime to meet other players; the full guide is in the docs.
