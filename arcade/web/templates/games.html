Popular Latest

Any HTML page you inscribe can be an app here. Put an app object (or game, as older cards do) in the inscription's JSON and it appears on this tab on every arcade, ranked by what people say about it. Inscribe a new version with the same name to replace the card.

{
  "app": {
    "name": "My App",
    "description": "One line about it.",
    "version": "1.0",
    "players": "1-8",
    "multiplayer": true,
    "wallet": true,
    "media": true,
    "family": "my-app",
    "cover": "<txid of a picture you inscribed>",
    "genre": "puzzle"
  }
}

Only name is required. A multiplayer app uses arcade.realtime to meet other players. An app that trades, pays, sends, mints or signs with the player's wallet says "wallet": true: Open then waits until the player ticks Wallet access on its card. An app that uses the wallet without saying so is stopped the first time it asks. An app that uses the camera or microphone (a video call) says "media": true: its card shows a Camera & microphone switch, off until the player turns it on. The full guide is in the docs.
