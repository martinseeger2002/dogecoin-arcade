What one of these is. Somebody priced a piece in their own browser and handed this node the signature: one coin of theirs in, one payment out to themselves, the price fixed in the bytes they signed. The piece is still theirs — this node holds a signature, not the coin, and it could not spend the piece if it wanted to.
How one ends. There are three ways and this page says which one happened.
  • A buyer completes it, a block spends the piece, and both sides get what they priced.
  • The seller spends that coin on something else. That is cancelling it. There is no withdraw button anywhere, and there is not going to be one: the signature has already left their browser, and a page cannot unsay it. The only thing that stills a signature is a transaction that spends what it was made from.
  • The time runs out, which means this node stops advertising it. Nothing inside a signature expires — there is no lock time in a leg — so anything already handed to a buyer is still good until a block spends the piece, past that date or not.
So the difference between the first and the second is who spent it, and this node cannot always tell. What it can tell you is whether the piece is still there, which is the only part of a listing it ever controlled.
