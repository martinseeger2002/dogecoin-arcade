Run your own

Everything needed to stand up another arcade is served from this one: the program, and a copy of its index so you do not start by re-reading the chain from the beginning.

Install it

curl -O {{ here }}/source.tar.gz
curl -O {{ here }}/source.tar.gz.sha256
sha256sum -c source.tar.gz.sha256
tar xzf source.tar.gz
python3 installer/install.py

The installer fetches Pepecoin Core, verifies its checksum and its signature, writes both configs, registers the services and starts everything. It needs Python and nothing else.

Start from a copy of the index

Reading a chain from its floor is correct and slow, and every node has already done it. These are copies of this node's indexes — derived state, so the same blocks read by the same rules give the same rows on any machine.

{% if copies %}

It is a convenience, not an authority. A downloaded index is somebody else's claim about the chain. Each one says the height it was taken at and carries two digests of what it holds; re-read from the floor yourself and compare them, and you have proved it rather than trusted it.

What is not in it: messages, the address book, and any key. Those are private to the node that holds them, and a bootstrap that carried them would publish somebody's conversations.
