Arcades

Every arcade that has said on the chain who runs it. Anybody can run a copy; this is how you tell them apart — by who runs them, not by what their name looks like.

How to read this. Each arcade announced its web address from its own fee address, in a transaction only that address's key could sign, so the chain proves who made each announcement. But anybody can announce any address, so your browser also asks each site which fee address it uses. Verified means the site and the chain agree. Anything else, be careful: a look-alike can copy a page, not a key.
