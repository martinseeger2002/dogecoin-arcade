    What the words bring back

    Signing in with your twelve words, on any device, on any node running this application, gets back:

    • Your name, once it is on the chain
    • Every coin on every chain this application holds one on
    • Every NFT and token any of those addresses holds
    • The ability to publish your key again and be written to

    All of it, because all of it is derived from the same twelve words. There is nothing else to keep for any of this.

    What stays in this browser

    Two things do not come back with the words, because they were never derived from them — they are notes this browser kept:

    • Your message history. Every message you have opened or sent is decrypted and stored here, in this browser, and nowhere else — that is what keeps this node from reading them. Signing in on a different device opens the same account, but its inbox starts empty; it has to scan the chain again to find what is addressed to it, and it can only open messages sent after that device knew the account existed.
    • Your address book. Also this browser's alone, for the same reason: a node holding everybody's address book would know who talks to whom without opening a single message. A new device starts with an empty book and re-adds people by searching their @tag.

    Neither is a security problem — nothing of value lives only there — but it is worth knowing before you need it: a new browser is a fresh start for messages and contacts, not just a fresh tab.

    An extra copy of your encrypted wallet

    This node already hands your encrypted wallet to anyone who asks for it by your name — that is what makes signing in from a new device possible at all. Downloading a copy of your own does not create a new way in; it means you are not depending on this particular node keeping it forever.

    It is useless without your password — but if you ever forget which node you signed up on, or that node is gone, this file and your password open the wallet at any node’s join page, which asks for the file and the password and never for your words. (Lost the password? Restore, reached from Sign in, is the one page that takes the words, and it never sends them.) A node you hand it to keeps no copy, so the copy on your disk is the copy.
