One arcade, two starting points. Every module runs everything. Core modules only runs the crypto cores (the chains and their wallets, sync and borrowing, send and receive, the address book, accounts, settings, help and the mesh link) and opens in ArcadeCore. Either can open in any look. The Apps tab groups the apps by kind; a node module added from a package, such as DigiDollar, is under Apps → Node modules. A module switched off keeps its data for when it is on again.
